# 秒杀项目 · 压测报告（模板，按天往里填）

> 规矩：**所有数字必须来自 `loadtest/report_*.json`，不许编。**
> 每次压测前先重置库存：`docker compose down -v && docker compose up -d`（或 `TRUNCATE seckill_order; UPDATE sku_stock SET stock=1000, sold=0 WHERE sku_id=1001;`）
> 压测与应用**同机**要注明，否则数字没有可比性。

---

## 一、环境

| 项 | 值 |
|---|---|
| CPU / 内存 | （填，如 i7-12700 / 32G） |
| 系统 | Windows 11 + Docker Desktop（WSL2） |
| JDK | 17.（填） |
| 应用与压测是否同机 | 是（同机会互相抢 CPU，数字偏保守） |
| 中间件 | MySQL 8 / Redis 7 / RabbitMQ 3.13（docker compose，未调参） |

## 二、方法

- 脚本：`loadtest/bench.py`（Python 标准库，多线程同步压测）
- 参数：`--total 5000 --concurrency 200 --sku 1001`
- 每个虚拟用户 `userId` 不同（模拟真实一人一单）；另跑一组 `userId` 相同验证一人一单正确性
- 统计口径：QPS = 成功请求数 / 总耗时；P95/P99 由脚本输出
