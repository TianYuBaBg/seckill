# D1 环境：装什么、怎么验、坑在哪

> **D1 拆成两步，先拿一个小的确定性胜利**（降低启动痛苦）：
>
> **D1a（约 20 分钟，不用重启电脑）**：只装 JDK 17 + Maven，配好阿里云镜像，然后在 `D:\me\seckill` 执行
> `mvn -q -DskipTests compile` → 看到**没有报错、生成 `target/classes`** 就算 D1a 完成。
> 这一步证明"代码本身没问题、网络和工具链是通的"，跟 Docker 无关。
>
> **D1b（约 40 分钟，可能要重启）**：装 Docker Desktop（WSL2）→ `docker compose up -d` → `mvn spring-boot:run`
> → `python tools/verify.py --day 1` 全 PASS，才是真正的 D1。
>
> 如果今晚只来得及做 D1a，就在 PROGRESS.md 写「D1a 完成」，我不催，第二天补 D1b。

> 目标：`docker compose up -d` 三个容器都 healthy，`mvn spring-boot:run` 起来后
> http://localhost:8080/actuator/health 返回 `{"status":"UP"}`。
> 全程约 60 分钟，其中 Maven 第一次拉依赖最慢（配好镜像 3~5 分钟，不配可能 30 分钟）。

## 1. 装三件套

| 工具 | 版本 | 验证命令 | 期望输出 |
|---|---|---|---|
| JDK | 17（Temurin / Adoptium 都行） | `java -version` | `17.x.x` 开头 |
| Maven | 3.9.x | `mvn -v` | 第一行 `Apache Maven 3.9.x` |
| Docker Desktop | 最新 | `docker -v` | `Docker version 2x.x` |

> ⚠️ 装 JDK 时记住安装路径，后面要设 `JAVA_HOME`（指向 JDK 根目录，不是 bin）。
> ⚠️ JDK 别用 21/22 —— `pom.xml` 里写的是 `<java.version>17</java.version>`，用 21 虽然能跑但多一个变量。

## 2. 配 Maven 镜像（最省时间的一步）

编辑 `C:\Users\Administrator\.m2\settings.xml`（没有就新建），在 `<mirrors>` 里加：

```xml
<mirror>
  <id>aliyun</id>
  <mirrorOf>central</mirrorOf>
  <name>阿里云公共仓库</name>
  <url>https://maven.aliyun.com/repository/public</url>
</mirror>
```

## 3. 起容器

```powershell
cd D:\me\seckill
docker compose up -d
docker compose ps          # 等三个都是 healthy，mysql 可能要 20 秒
```

- MySQL 8 → `localhost:3306`（root / root，库 seckill，第一次启动自动执行 `sql/init.sql`）
- Redis 7 → `localhost:6379`
- RabbitMQ → 管理台 http://localhost:15672 （guest / guest）

## 4. 起应用

```powershell
mvn spring-boot:run
```

看到 `Started SeckillApplication in x.x seconds` 就算成功；另开一个窗口：

```powershell
curl http://localhost:8080/actuator/health
# {"status":"UP", ...}
```

## 5. 自检一把（以后每天都用）

```powershell
python tools/verify.py --day 1
```

输出全 `[PASS]` 再叫我验收。有 `[FAIL]` 就把那一行发我。

## 5.5 开发工具（用哪个、怎么配）

| 用途 | 工具 | 说明 |
|---|---|---|
| 写代码 | **IntelliJ IDEA Community**（免费） | 10 年 Java 的人用 IDEA 最顺；Community 版缺的只有 Spring 配置提示、Database 面板、HTTP Client，这个项目都不刚需 |
| 让 AI 改代码 | **Claude Code** | 能在终端里自己跑 mvn/git/docker 并验证，分工：它写、你跑、我叫验收 |
| 看数据库 | **DBeaver Community**（免费）或 `docker exec` | 看库存/订单，别为这个买 Navicat |
| 不建议 | IDEA Ultimate / VS Code / Trae（核心业务） | Ultimate 30 天试用到期常卡在项目关键期；VS Code 的 Java 重构调试比 IDEA 差一档；Trae 一次改多文件容易乱，留着写前端和 README |

### IDEA 打开项目 5 步

1. `File → Open` → 选 **`D:\me\seckill` 文件夹**（不是 pom.xml）
2. 右下角 Maven 提示 → Trust / Import
3. `File → Project Structure → SDK` 选 **JDK 17**（不是 21，pom 里定的是 17）
4. `Settings → Build, Execution, Deployment → Compiler → Annotation Processors` → 勾 **Enable annotation processing**
   （不勾的话 Lombok 的 `@Data` / `@Slf4j` / `@RequiredArgsConstructor` 会一片红，代码其实没错）
5. Run 配置选 `SeckillApplication` → 运行

### 两个省事设置

- 插件市场装 **Chinese (Simplified) Language Pack**（官方中文包），界面中文，少分心
- `Settings → Build Tools → Maven → User settings file` 指向你改过的 `settings.xml`（第 2 步那份），否则 IDEA 会自己重新拉一遍依赖、又卡一次

### DBeaver 连 docker 里的 MySQL

新建连接 → MySQL → `localhost:3306` / `seckill` 库 / root / root → 驱动自动下载 →
看 `sku_stock`（库存 1000）和 `seckill_order`（压测后应该只有 1000 条以内，且 `user_id` 不重复）。

### 用 Claude Code 的三条规矩

1. **一次只让它改一个方法**：给它具体范围（「只改 `SeckillServiceImpl.createOrder`，用乐观锁，别动别的文件」）
2. **它说完成后你自己跑 `python tools/verify.py --day N`**，绿了才算完
3. **看不懂的代码就问我**——面试只会问你自己能讲清楚的东西，AI 写的代码讲不出来等于白做

## 6. 常见报错对照表

| 报错 / 现象 | 原因 | 怎么办 |
|---|---|---|
| `Ports are not available: 3306 already in use` | 本机装了 MySQL 或别的容器占了端口 | `netstat -ano \| findstr :3306` 找到 PID，`taskkill /PID xxx /F`，或先停掉本机 MySQL 服务 |
| `Communications link failure` | 容器没起完 / 没起 | `docker compose ps` 看 mysql 是否 healthy，`docker logs seckill-mysql` |
| `Public Key Retrieval is not allowed` | MySQL 8 默认认证插件 | 连接串已带 `allowPublicKeyRetrieval=true`，若自己改了连接串记得保留 |
| `Unknown database 'seckill'` | init.sql 没执行（首次启动才执行） | 见下面「重灌数据库」 |
| 时间差 8 小时 | 时区 | 连接串已带 `serverTimezone=Asia/Shanghai`，容器也设了 `TZ` |
| `mvn` 下载卡在 0% | 没配镜像 | 回到第 2 步 |
| Docker 报 `WSL 2 installation is incomplete` | WSL2 没装 | `wsl --install` 后重启，Docker Desktop 设置里勾 WSL2 backend |
| IDEA / 终端中文乱码 | 编码 | `chcp 65001` |

### 重灌数据库（改过 init.sql 或想重置库存）

```powershell
docker compose down -v      # -v 会删数据卷，库存回到 1000
docker compose up -d
```

### 进容器看数据

```powershell
docker exec -it seckill-mysql mysql -uroot -proot -e "select * from seckill.t_seckill_stock;"
docker exec -it seckill-redis redis-cli
```
