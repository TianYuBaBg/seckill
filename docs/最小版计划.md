# 最小可讲版 · 7 天 × 20 分钟

> 给"觉得项目太大做不完"的版本。砍掉一切不影响面试的东西，只保留**最能证明你能力的三件事**。
> 每天 20 分钟，超过 20 分钟就停，第二天继续。做不完不丢人，没开始才亏。

## 先看结论：你一共只需要写大约 120 行代码

| 要写的东西 | 大概行数 | 难度 |
|---|---|---|
| `createOrder` 数据库版（乐观锁扣库存） | ~30 行 | 简单：一次 update + 判断影响行数 |
| `createOrder` Redis+Lua 版 | ~35 行 | 中等：调一次脚本，判断返回值 |
| `seckill.lua` 脚本 | ~15 行 | 简单：3 个 if |
| `detail` / `result` 两个查询接口 | ~20 行 | 简单：一次查询 |
| 一人一单判断 | ~20 行 | 简单：唯一索引 + 捕获异常 |

其余（MQ 异步、限流、延迟队列回补、故障演练、Docker 化、单测）**全部标为选做**，一个都不做也不影响你面试讲这个项目。

## 为什么砍掉这些也不亏

| 砍掉的 | 为什么可以砍 |
|---|---|
| MQ 异步削峰 | 面试问到了你有话可说（提纲 Q2/Q3 已经写好了答案），但**不需要真写**才讲得出来 |
| 限流 | 同上，Q5 的答案不依赖代码 |
| 延迟队列回补 | Q7 的答案不依赖代码 |
| 故障演练 | 是加分项，不是必需项 |
| Docker 化 / 单测 | 锦上添花，等你哪天有精神再说 |

**核心逻辑：面试官要听的是"你为什么这么选、遇到什么问题、怎么验证的"，不是"你写了多少功能"。**
不超卖（Q1）+ 性能对比（Q6）+ 一人一单（Q4）这三条讲透，比堆 10 个功能更值钱。

## 今晚 D1a 的 20 分钟怎么花

1. **0–8 分钟**：装 JDK 17 → https://adoptium.net/temurin/releases/?version=17
   下载 `.msi`，一路下一步；安装向导里把 **Set JAVA_HOME variable** 勾上。
2. **8–15 分钟**：装 Maven → https://maven.apache.org/download.cgi
   下 `apache-maven-3.9.x-bin.zip`，解压到 `C:\tools\`（路径别带空格和中文），
   把这个目录下的 `bin` 加进系统环境变量 `Path`。
3. **15–20 分钟**：**重开**一个 PowerShell，验证并编译：

```powershell
java -version          # 看到 17.x 就对了
mvn -v                 # 看到 Apache Maven 3.9.x
cd D:\me\seckill
mvn -q -DskipTests compile
```

最后一条**没有任何输出就是成功**（`-q` 是静默模式，Maven 成功时不说话）。

然后在 `PROGRESS.md` 里加一行：

```
| 2026-10-25 | D1a | 装 JDK17+Maven，mvn compile 通过 | | 20min |
```

commit + push，跟我说「D1a 完成」。
